Histograms: fraction of each group, same scale in every lane; solid line = median, dotted = mean. Drag to zoom (sets the limits), double-click to reset, the camera icon saves an SVG.

Removed points

Statistics. Within groups: Spearman ρ, two-sided permutation p (5,000 shuffles), Holm-corrected across the groups shown. Between groups: two-sided Mann-Whitney per pair (normal approximation with tie correction), Holm-corrected within each variable; Kruskal-Wallis across 3+ groups. Far outliers: per group, beyond the fence × IQR from the quartiles; log-scaled columns are judged on asinh(v / c). Symmetric log axes show zero and negative values; the region within ±c of zero is linear.
